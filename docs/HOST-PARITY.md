# Host Parity Matrix

Ask LLM gives every host the same tools, workflows and provider options where the host can carry them; each difference below is a deliberate host limit, not an oversight. Provider differences live in [PROVIDER-PARITY.md](PROVIDER-PARITY.md); this page covers hosts only. `ask-llm doctor` prints the column for each installed host.

## Equal everywhere (tested)

- **Tool names and input schemas.** Pi has no MCP client, so its extension registers `ask-llm`, `multi-llm` and `ask-cursor-agent` natively from the same zod schemas the MCP server registers, converted the way the MCP SDK lists them. `src/__tests__/host-parity.test.ts` lists the server's tools through a real MCP client and fails when a tool name or an input schema differs from Pi's.
- **Responses.** Both hosts run one request path (`runAskLlm`, `runMultiLlm`), so `ask-llm` returns the same `AskResponse` (Pi puts it in the tool result's `details.structuredContent`) and `multi-llm` the same report.
- **Validation.** Cross-field rules (for example `sandbox` only with `provider: "codex"`) are checked by the same zod schema on every host; unsupported combinations are errors, never stripped.

## Deliberately non-equal

- **Pi aliases.** `ask-codex`, `ask-gemini`, `ask-grok`, `ask-ollama`, `ask-antigravity` and `ask-multi` stay on Pi as deprecated aliases. `ask-multi` also takes per-provider options, which `multi-llm` does not.
- **Diagnostics on Pi.** `diagnose`, `ping` and `get-usage-stats` are MCP-only; on Pi use `ask-llm doctor`.
- **Pi output.** Pi bounds displayed text to its 50KB/2000-line limit and says so when it truncates; structured payloads remain complete.
- **Hooks, subagents and the Stop gate** need host lifecycle support: only Claude Code (through the plugin) has per-edit hooks, isolated reviewer agents and a blocking Stop gate. Pi's codex-pair extension reviews each edit but cannot block a turn. Other skills-folder hosts pair on demand through the `ask-llm-codex-pair` skill. Pairing is off on every host until the user enables it.
- **Skills.** Claude Desktop is tools only. Antigravity reads skills from `~/.gemini/config/skills`, which the pinned skills CLI cannot write, so `ask-llm setup` prints the copy command.
- **Tool prefixes and command syntax** (for example `mcp__ask-llm__ask-llm`, or Pi's `/skill:ask-llm-review`) follow each host.
