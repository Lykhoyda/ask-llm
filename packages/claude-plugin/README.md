# Ask LLM compatibility bridge

Existing installations keep working through this bridge. New users should follow the [Ask LLM install guide](https://lykhoyda.github.io/ask-llm/start/install) and run `ask-llm setup`; a separate plugin installation is no longer part of onboarding.

For an existing plugin or Pi npm installation, follow [Migration](https://lykhoyda.github.io/ask-llm/reference/migration) before removing anything. Setup leaves unverified Pi npm sources and customised entries unchanged with guidance. Preserve resource filters and settings, then verify the replacement before retiring the bridge.
